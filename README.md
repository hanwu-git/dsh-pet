# 边牧桌宠 · Border Collie Pet（v2.0）

一只住在你桌面上的边牧，帮你盯着 **所有工作区** 的任务：跑完弹绿气泡、出错弹红气泡、等你确认弹黄气泡。固定之后，DSH 最小化它也不会消失，始终待在屏幕最前面。不喜欢边牧？v2.0 起可以把整个宠物角色交给 **内嵌的 KuroCat 猫引擎**——打字联动、捏猫、3D、OBS 全套能力，与 DSH 深度整合。

> 一只会看家的边牧。任务跑完它抬头告诉你，出错它歪头提醒你，等你确认它就坐在那儿看着你。当然，你也可以让一只会敲键盘的小黑猫接班。

## 功能

### 内嵌 KuroCat 猫引擎（2.0.0 新增）

设置 → 桌面宠物 → 宠物形象，三种形态：

| 形态 | 说明 |
|---|---|
| 🐕 边牧（内置） | 页内宠物 + 桌面固定小窗，轻量纯通知 |
| 🐱 **内嵌猫（v2.0 推荐）** | KuroCat 引擎随插件内置（`pet/` 目录）：**打字联动**（全局键盘钩子，猫跟你一起敲键盘）、**捏猫**（MCP 工具 + 右键菜单）、2D/3D 双引擎、6 皮肤 + 大肥鱼、OBS 透明源、输密码闭眼隐私守卫 |
| 🐱 外部官方猫 | 转发到你手装的官方 KuroCat（端口 27420），兼容旧路径 |

内嵌猫的生命周期（v2.0 设计）：

- **可独立运行**：不启动 DSH 也能直接运行宠物
- **自动接入**：DSH 启动时探测端口——已有实例直接接管开始跟踪任务状态，绝不双开（单实例保证）
- **按设置自启**：DSH 启动时宠物未运行，由「DSH 启动时自动拉起」设置决定
- **退出询问**：关闭 DSH 时若宠物在运行，弹窗问你「是否同步关闭」，选择会被记住（本次保留 / 总是保留 / 同步关闭）
- **端口共存**：内嵌实例用 27430+，与你手装的官方 KuroCat（27420）互不干扰

### 等你确认 → 自动呼起（2.0.0 增强）

Agent 提问或请求审批时：小猫冒泡「等你确认」的同一秒，**DSH 主窗自动弹到前台**并跳转到对应会话——你不用自己去翻。

### 自定义宠物图片（0.5.0）与三色气泡、固定桌面

与之前版本一致，边牧形态下全部保留。详见下文与 [docs/DETAIL.md](docs/DETAIL.md)。

设置 → 桌面宠物 → 宠物图片：

- **选择图片…**：从本机选一张图（JPG / PNG / WebP / GIF 均可），前端自动转为 PNG 并缩放到合适尺寸后上传
- **应用这张图片**：页内宠物与桌面固定小窗 **同时切换**，无需重启 DSH
- **恢复默认**：一键换回边牧小狗
- 图片会 **复制进插件目录** 保存（`.companion/pet-custom.png`），之后删除、移动、重命名原文件都不影响显示
- 桌面小窗会自动把带透明通道的图片合成到键色上（装有 Pillow 时），避免边缘出现紫边
- 保持宽高比缩放，超大会自动缩小，不会撑爆布局

设置页标题旁会显示当前插件版本号。

### 三色任务气泡

跨工作区监控，任何会话的任务状态变化都会让它抬头：

| 气泡 | 触发时机 | 样式 |
|---|---|---|
| **执行完成** | 任意工作区的任务从运行转为结束 | 浅绿底 · 绿边 |
| **执行失败** | 任务抛出错误（附简短原因） | 淡红底 · 红边 |
| **等你确定** | Agent 向你提问，或请求审批 | 淡黄底 · 黄边 |

气泡**不会自动消失**——你不会再错过任何一条。新结果会覆盖上一条。

### 点它一下，DSH 就到前台

点小狗 = 把 DSH 主窗叫到最前面，同时收起气泡。它就是你桌面上的 DSH 快捷方式。
按住拖动可以把它挪到任何位置。

### 固定到桌面

页面右下角的宠物右上角有个 📌 按钮：

- **点一下**：宠物变成一个独立置顶小窗，DSH 最小化、被其他窗口盖住时它依然在最前
- **再点一下**：收回页面内显示
- 固定状态会被记住，DSH 重启后自动回到桌面

### 尺寸三档

设置 → 桌面宠物 里可选：

| 档位 | 尺寸 |
|---|---|
| 大 | 300 × 272（默认） |
| 中 | 150 × 136 |
| 小 | 100 × 91 |

切换时保持左上角位置不动，气泡字号同步缩放。

### 气泡提示音

每种气泡配一个可区分的系统音：完成 = 叮、失败 = 警告、等你确定 = 提示。设置页里可以直接**试听**三种音效，也可以整体关掉。

## 安装

### 从插件市场安装

在 DSH 中添加市场源地址，然后搜索「边牧桌宠」安装。

### 手动安装

```bash
# 在 DSH profile 目录下
pnpm add <git-repo-url>
```

或在 DSH 的插件管理页面用 `link:` / git 地址安装。

## 系统要求

| 项目 | 要求 |
|---|---|
| **操作系统** | **Windows 10 / 11**（桌面置顶窗基于 tkinter + Win32 API，不支持 macOS / Linux） |
| **DSH** | 0.2.x 及以上 |
| **Python** | **3.8+，需带 tkinter**（用于渲染桌面小窗） |

### 关于 Python

「固定到桌面」功能需要一个带 tkinter 的 Python。插件会按以下顺序自动查找：

1. DSH 自带的运行时：`%USERPROFILE%\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\pythonw.exe`
2. 用户级安装：`%LOCALAPPDATA%\Programs\Python\Python3xx\pythonw.exe`
3. 系统级安装：`C:\Python3xx\pythonw.exe`
4. 环境变量 `PATH` 中的 `pythonw.exe` / `python.exe`

**没有 Python 也能用**——页内宠物、三色气泡、点击跳转全部正常工作，只是无法固定到桌面。此时点 📌 会给出明确提示。

Windows 用户如果没装 Python，推荐从 [python.org](https://www.python.org/downloads/windows/) 安装，安装时勾选 **tcl/tk and IDLE**。

想快速确认自己的 Python 能不能用：

```powershell
python -c "import tkinter; print('tkinter OK')"
```

## 常见问题

**Q：点了 📌 没反应 / 提示固定失败？**
多半是找不到可用的 Python。用上面的命令确认 `import tkinter` 是否成功。

**Q：桌宠窗口出现粉色方块？**
这是 tkinter 键色透明在某些显示环境下的兼容问题，请更新到最新版本。如果仍有问题，欢迎提 issue 并附上显卡/远程桌面信息。

**Q：任务完成了但没弹气泡？**
确认宠物处于固定状态（未固定时页面内的宠物也会弹气泡）。如果两个都没有，请附上 `.companion/host.log` 的最后几行。

**Q：桌宠挡到东西了？**
直接拖走，或者点 📌 收起来。

**Q：能同时开多个 DSH 吗？**
每个 DSH 实例会各自拉起一个桌宠窗口。

## 技术实现

- **Host**（`pet-service.js`）：DSH 函数插件，注册 `POST /border-collie-pet/rpc` 路由（走 connection 信任墙鉴权），监听 `agent/status`、`agent/error`、`session/event` 把任务状态写入 `state.json`
- **桌面窗**（`companion.py`）：tkinter 无边框置顶窗，轮询状态文件渲染气泡；ctypes 调用 Win32 API 实现窗口呼前
- **Client**（`client.js`）：页面内宠物 + 📌 按钮 + 设置页，通过 `settings.section` 槽位注入到设置左侧导航

不依赖任何 `@deepseek-ai/*` 运行时包（只用 Node 内置模块），因此可以独立分发。

更多实现细节见 [docs/DETAIL.md](docs/DETAIL.md)。
